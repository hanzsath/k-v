# Knowledge Vault

> A personal knowledge base for learning, building, experimenting, and growing.

`k-v`  is my personal knowledge vault, built with [Obsidian](https://obsidian.md/). It brings together everything I learn, practice, discover, and experience along my journey.

## What You'll Find Here

- **Technical Notes** - Linux, Bash, networking, programming, and system administration.
- **Cybersecurity** - Web security, penetration testing, CTF challenges, and security research.
- **Practical Labs** - Hands-on experiments, command examples, troubleshooting, and lab documentation.
- **Projects** - Personal projects, automation scripts, infrastructure, and experiments.
